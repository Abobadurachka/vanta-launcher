# Друзья и LAN-миры VANTA

## 1. Добавление в друзья

1. Оба игрока открывают вкладку «Друзья».
2. Каждый копирует собственный VANTA-код.
3. Передайте друг другу коды в личном сообщении.
4. Введите код друга, укажите имя и нажмите «Добавить в друзья».
5. Оба компьютера должны быть подключены к одной локальной сети Wi-Fi/Ethernet.

## 2. Как открыть мир (хост)

1. Выберите профиль в VANTA и нажмите «Играть».
2. В Minecraft откройте одиночный мир.
3. Нажмите Esc → «Открыть для сети» → «Начать мир для сети».
4. Minecraft показывает в чате строку с портом LAN. VANTA отслеживает локальный Minecraft multicast-анонс и обычно получает этот порт автоматически.
5. В списке друга должен появиться статус «Открыл LAN-мир».

Если автоматическое обнаружение заблокировано настройками сети или брандмауэром Windows, введите показанный Minecraft порт в поле «Порт вручную» и нажмите «Поделиться».

## 3. Подключение (гость)

1. Установите профиль с точно такой же версией Minecraft и загрузчиком, какие указаны в карточке друга.
2. Убедитесь, что оба компьютера в одной локальной сети.
3. Нажмите «Подключиться» в карточке друга.
4. VANTA запустит выбранный совместимый профиль и передаст локальный адрес/порт Minecraft. Для Minecraft 1.20+ используется Quick Play, для старых клиентов — legacy `--server`/`--port`.

VANTA не переносит мир к гостю и не запускает отдельный dedicated server. Мир работает на компьютере друга-хоста; если хост выключит Minecraft или закроет LAN, подключение прекратится.

## 4. Сеть и безопасность

- Это локальная сеть, а не глобальная система приглашений через интернет. Игроки из другой Wi-Fi-сети не увидят LAN-анонс.
- VANTA отправляет короткие UDP presence-пакеты только в multicast-группу с TTL=1; публичный IP или данные в облако не отправляются.
- Friend code — идентификатор контакта, а не пароль. Minecraft Open to LAN может быть доступен другим устройствам в той же сети, не только контактам из VANTA.
- Подключайтесь только к доверенной домашней/частной сети.
- Если multicast заблокирован роутером/Windows Firewall, попробуйте ручной ввод порта; при запросе Windows разреши VANTA и Java только для частной сети. Брандмауэр не нужно отключать целиком.
- Для подключения через интернет понадобится отдельный защищённый relay/signaling-сервис и серверная инфраструктура. В этой версии такой сервис не развёрнут.

## 5. Совместимость версий

Vanilla перечисляет версии из Mojang manifest. Fabric и NeoForge показывают опубликованные совместимые сборки для выбранной версии Minecraft. Загрузчики не выпускают версии для каждого релиза Minecraft, поэтому пустой список означает отсутствие опубликованной совместимой сборки. NeoForge использует отдельную схему имён версий; VANTA сопоставляет ветку с Minecraft (например, 1.21.1 → 21.1.x, 26.1 → 26.1.x).
