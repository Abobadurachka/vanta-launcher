VANTA LAUNCHER — CHANGELOG
=========================
Версия: 1.1.0-beta.2
Канал: PRE-RELEASE
Дата: 20.11.2026

ИСПРАВЛЕНО В beta.2
- Исправлена совместимость типов releaseNotes в обработчике автообновления: типы
  заметок допускают null, как это определено electron-updater.
- Сборка TypeScript больше не должна останавливаться на обработчиках update-available
  и update-downloaded.

ИЗМЕНЕНО
- Nebula Launcher переименован в Vanta Launcher.
- Полностью обновлена визуальная система: новая палитра, типографика, карточки,
  навигация, состояния наведения и анимации переходов.
- Создан новый фирменный знак Vanta и обновлены иконки приложения/установщика.
- Главный экран использует новую панорамную иллюстрацию 1672x941 вместо старой
  CSS-графики с низкой детализацией.
- Добавлена стартовая анимация при каждом запуске приложения.

КАТАЛОГ MODRINTH
- Каталог теперь открывается как отдельная полноразмерная библиотека проектов.
- Поиск работает вместе с фильтрами по категориям, версии Minecraft и загрузчику.
- Добавлены сортировки: популярные, подписчики, недавно обновлённые, новые,
  релевантные.
- Добавлена пагинация по 24 проекта на страницу и общее количество результатов.
- Для каждого проекта показываются иконка, описание, категории, загрузки,
  подписчики, кнопка перехода на Modrinth и установка.
- Пустой поисковый запрос показывает популярные совместимые проекты, а не пустую
  выдачу. API не выгружается целиком за один запрос: каталог листается страницами.

ОБНОВЛЕНИЯ
- Добавлена вкладка «Обновления» с журналом изменений.
- Добавлена интеграция electron-updater для Windows NSIS.
- Добавлены проверка обновлений при запуске и периодическая проверка раз в 10 минут,
  загрузка и установка обновления, статус «Вышла новая версия лаунчера».
- Чтобы автообновления реально работали, нужно опубликовать beta.yml, latest.yml, установщик
  и blockmap на HTTPS-сервере и прописать его URL в src/main/update-config.ts.

УСТАНОВКА
- Установщик называется Vanta-Launcher-Setup-1.1.0-beta.2-x64.exe.
- Создаются ярлыки на рабочем столе и в меню «Пуск».
- Сохранён прежний каталог данных Nebula, чтобы не потерять существующие профили,
  параметры и локальные игровые файлы при переименовании.

БАЗОВЫЕ ФУНКЦИИ
- Сохранены существующие профили, загрузчики, менеджер модов, импорт сборок,
  диагностика и восстановление из предыдущей версии.
