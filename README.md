# VANTA Launcher

![Version](https://shields.io)
![Downloads](https://shields.io)
![Platform](https://shields.io)

Современный и быстрый лаунчер для Minecraft с встроенным каталогом модов **Modrinth** и системой автоматических обновлений.

## ✨ Основные возможности

- 🚀 **Быстрый запуск** и удобное управление игровыми профилями.
- 📦 **Каталог Modrinth** — поиск и установка модов, сборок и шейдеров в один клик.
- 🔄 **Автообновления** — лаунчер сам проверяет и устанавливает новые версии через GitHub Releases.
- 🎨 **Современный интерфейс** с гибкими настройками и админ-панелью.

## 📥 Скачать и установить

1. Перейдите в раздел **[Releases](https://github.com)**.
2. Скачайте актуальный установщик **`Vanta-Launcher-Setup-...-x64.exe`**.
3. Запустите установщик. Дальнейшие обновления будут приходить автоматически!
