VANTA LAUNCHER 1.3.0-beta.1 · PRE-RELEASE · 22.11.2026

Добавлено:
+ Полные списки Fabric loader из Fabric Meta для выбранной версии Minecraft.
+ Полные доступные списки NeoForge по официальным Maven metadata и правильной ветке Minecraft.
+ Полный список Forge-вариантов из Maven metadata; recommended/latest подняты вверх.
+ Предупреждение и блокировка создания профиля, если загрузчик не поддерживает выбранную версию игры.
+ Система друзей VANTA с уникальным friend code, добавлением/удалением контактов и локальным presence.
+ LAN-discovery на multicast в пределах одной локальной сети.
+ Автоматическое чтение стандартного Minecraft LAN-анонса и реального порта мира хоста.
+ Ручной запасной ввод LAN-порта.
+ Подключение прямо к миру друга: Quick Play для Minecraft 1.20+ и legacy server/port arguments для более старых версий. Перед подключением сверяется точный build загрузчика.

Ограничения:
- Vanilla доступна для официальных версий Mojang manifest.
- Fabric/NeoForge доступны только для Minecraft-веток, для которых их разработчики выпустили сборки.
- Система друзей в этой версии работает внутри одной локальной сети; интернет-relay не включён.
- VANTA friend code идентифицирует контакт, но не защищает LAN-мир от других устройств той же сети.
- Поддержка старых Alpha/Beta использует резервное определение Java 8; week-based snapshots используют Java 17 или 21 по периоду выпуска.
