# VANTA Launcher 1.4.0 — Stable Release
Дата: 22.11.2026

## Визуальные улучшения
- Полностью обновлена визуальная система в стиле premium glass UI: глубокая тёмная палитра, мягкие стеклянные панели, более точные границы, контраст и состояния элементов.
- Главный экран адаптирован для Full HD: увеличенная hero-карточка, читабельная типографика, улучшенные метаданные профиля и системной диагностики.
- Панель каталога Modrinth получила более ровную сетку карточек: три колонки на стандартном широком окне и четыре на очень широком экране; текст и кнопки переносятся без наложений.
- Обновлены карточки профилей, друзей, модов, сборок, диагностики, панели разработчика и автообновлений.
- Добавлены дополнительные адаптивные точки для окон от минимального размера до 1920×1080 и выше.
- Высокодетальный `src/renderer/assets/vanta-world.png` подключён непосредственно как Vite asset к hero-фону; логотип `src/renderer/assets/vanta.png` оставлен на месте.
- Улучшены четкость текста, SVG иконок и растровых ресурсов на Windows DPI 100%, 125% и 150%; масштабирование Chromium оставлено нативным, без искусственного device-scale-factor.
- Уменьшены риски переполнения: длинные строки переносятся, карточки используют `min-width: 0`, основная область имеет один управляемый вертикальный скролл.

## Окно Electron
- Стартовый размер окна: 1600×900.
- Минимальный размер окна: 1180×720.
- Окно центрируется и корректно разворачивается на весь экран.
- Добавлено появление окна после `ready-to-show`, чтобы убрать белую вспышку при старте.
- Сохранена прежняя идентичность приложения и каталог пользовательских данных для сохранения профилей и миров.

## Стабильные обновления
- Версия переведена на чистый SemVer `1.4.0`, без `beta`, `alpha` или `rc`.
- Канал `electron-updater` зафиксирован на `latest`; `allowPrerelease = false` и `allowDowngrade = false`.
- Проверка GitHub Releases выбирает только опубликованные стабильные релизы (`draft=false`, `prerelease=false`).
- Generic HTTPS feed использует только `latest.yml`; проверка больше не зависит от `beta.yml`.
- Публикация через `PUBLISH-GITHUB.bat` создаёт обычный GitHub Release (`releaseType: release`, `channel: latest`) и выставляет `prerelease: false`.
- Отключено определение prerelease-канала по суффиксу версии и генерация дополнительных channel manifests; для стабильной версии electron-builder генерирует `latest.yml`.
- Содержимое этого файла публикуется в теле GitHub Release для передачи заметок в `info.releaseNotes`.
- Сохранены `PUBLISH-GITHUB.bat`, `PUBLISH-GITHUB.ps1` и `scripts/publish-github-release.cjs`.

## Сохранённая функциональность
- Без изменений сохранены IPC и логика Vanilla/Fabric/Forge/NeoForge, установка и починка Minecraft-профилей, Modrinth, модпаки, RAM/Java, друзья/LAN, локальная админ-панель и журнал диагностики.
- Сохранены относительные импорты и файлы `src/renderer/assets/vanta.png` и `src/renderer/assets/vanta-world.png`.
