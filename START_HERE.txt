VANTA LAUNCHER 1.4.0 · STABLE RELEASE
====================================

СБОРКА УСТАНОВЩИКА WINDOWS:
1. Установи Node.js 22+.
2. Запусти SETUP.bat.
3. Дождись завершения сборки.
4. Открой release и запусти Vanta-Launcher-Setup-1.4.0-x64.exe.

ПУБЛИКАЦИЯ СТАБИЛЬНОГО ОБНОВЛЕНИЯ:
1. Создай публичный GitHub repository.
2. Запусти PUBLISH-GITHUB.bat.
3. Введи owner/repository и GitHub token с Contents: Read and write.
4. Скрипт публикует обычный стабильный Release с latest.yml и RELEASE_NOTES.md.

ПРОЕКТ:
- Версия приложения берётся из package.json.
- Канал обновления: latest (без Pre-Release).
- Ресурсы: src/renderer/assets/vanta.png и vanta-world.png.
- Старые профили и миры хранятся в прежнем пользовательском каталоге.

См. README_RU.md и UPDATE-CHANNEL-RU.md.
