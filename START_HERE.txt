VANTA LAUNCHER 1.3.0-beta.2 · PRE-RELEASE
=========================================

1) Установи Node.js 22 или новее.
2) Распакуй архив.
3) Запусти SETUP.bat.
4) Дождись создания release/Vanta-Launcher-Setup-1.3.0-beta.2-x64.exe.
5) Запусти установщик и открой ярлык VANTA Launcher.

Автообновления:
- Создай публичный GitHub-репозиторий для релизов VANTA.
- Запусти PUBLISH-GITHUB.bat и введи owner/repository и GitHub token.
- Скрипт встраивает адрес канала в обновляемую сборку, создаёт Pre-Release и прикрепляет metadata.
- После первой ручной установки сборки beta.2 следующие beta-релизы обнаруживаются автоматически при запуске и каждые 10 минут.
- Для альтернативного HTTPS-канала см. UPDATE-CHANNEL-RU.md.

Важно: для доставки обновлений нужен внешний источник релизов. Само редактирование кода в ChatGPT не публикует новую версию автоматически. Сначала нужно собрать и опубликовать Pre-Release.


Друзья / LAN:
- Оба игрока запускают VANTA и добавляют друг друга по VANTA friend code.
- Хост запускает профиль через VANTA, входит в одиночный мир, затем открывает его: Esc -> Открыть для сети.
- VANTA автоматически замечает LAN-анонс и порт; друг на том же Wi-Fi нажимает ПОДКЛЮЧИТЬСЯ.
- Если автоопределение не сработало, хост вводит порт из сообщения Minecraft в поле ПОРТ ВРУЧНУЮ.
- Для игры нужна одна LAN/Wi-Fi сеть и установленный профиль с той же версией игры, типом и точной версией загрузчика.
- Подключение через интернет в этом выпуске не реализовано; для него требуется relay-сервер.
