# Vanta Launcher 1.2.0-beta.3

**Статус: Pre-Release.** Desktop-лаунчер Minecraft Java Edition на Electron + React + TypeScript.

## Новое в 1.2.0-beta.3

- GitHub-канал из publish-конфигурации автоматически читается из `resources/app-update.yml` в установленном приложении.
- GitHub publisher явно использует канал `beta`, чтобы Pre-Release metadata совпадала с настройками electron-updater.
- Добавлен `PUBLISH-GITHUB.bat` для запуска публикации без ручного обхода PowerShell ExecutionPolicy.
- Добавлены отсутствовавшие renderer-типы для статуса обновлений и Modrinth API, чтобы интерфейс проходил полноценную TypeScript-проверку.

## Новое в 1.2.0-beta.2

- Настройка канала обновлений из админ-панели: GitHub Releases или Generic HTTPS.
- Проверка репозитория/манифеста и автоматическая проверка обновлений при старте и каждые 10 минут.
- Сценарий `PUBLISH-GITHUB.bat` для публикации Windows Pre-Release.

## Новое в 1.2.0-beta.1

- Полная визуальная переработка Aurora Glass: более глубокие поверхности, световые акценты, кинематографическая обложка, плавные появления и hover-анимации.
- Мягкие звуки интерфейса синтезируются через Web Audio API; переключатель звука находится в верхней панели. Никакие внешние аудиофайлы не загружаются.
- Добавлена локальная панель разработчика с первоначальной настройкой логина/пароля и последующим входом. Пароль не хранится открытым текстом: используется scrypt с индивидуальной случайной солью. Пять неудачных попыток блокируют вход на 60 секунд; сеанс истекает через 15 минут бездействия.
- Панель показывает версию приложения, Electron/Node, платформу, количество профилей, время работы и состояние release feed; предоставляет просмотр последних 100 строк лога и открытие полного журнала.
- Сохранена прежняя идентичность установленного приложения и каталог данных Nebula, чтобы не потерять существующие игровые профили и миры.

## Требования

- Windows 10/11 x64.
- Node.js 22 или новее для сборки исходников.
- Интернет для установки npm-зависимостей, игровых файлов, модов и Java.

## Сборка Windows Setup

1. Установи Node.js 22+ с https://nodejs.org/.
2. Распакуй архив.
3. Запусти `SETUP.bat`.
4. Скрипт устанавливает зависимости и запускает TypeScript/Vite build + electron-builder.
5. Готовый установщик появится в `release/Vanta-Launcher-Setup-1.2.0-beta.3-x64.exe`.
6. Запусти Setup. Установщик создаёт ярлык на рабочем столе и в меню «Пуск».

Альтернативные команды:

```powershell
npm.cmd install --no-audit --no-fund
npm.cmd run build
npm.cmd run dist:win
```

## Панель разработчика

Открой «Для разработчика» в боковой панели. При первом входе создай собственный логин и пароль (латинские буквы/цифры/`_.-` для логина, от 10 до 128 символов для пароля). После этого используй созданные данные для входа. Пароль не вшит в проект и не передаётся по сети. Файл с солью и хешем расположен в пользовательском каталоге приложения, в папке `NebulaLauncher/developer-admin.json`. Не делись им: хотя он не содержит пароль, это данные локальной учётной записи. Если забудешь пароль, закрой лаунчер и удали `%APPDATA%\nebula-launcher\Nebula Launcher\NebulaLauncher\developer-admin.json`; при следующем открытии панели можно будет создать новые учётные данные. Игровые профили и миры при этом не затрагиваются.

Панель — локальная защита от случайного доступа внутри приложения. Она не заменяет серверную авторизацию и не защищает от другого приложения/пользователя Windows, имеющего доступ к файлам текущей учётной записи.

## Обновления

В beta.3 GitHub-канал встраивается в `app-update.yml` при публикации через `PUBLISH-GITHUB.bat`; установленная версия автоматически подхватывает репозиторий и проверяет обновления при запуске и затем каждые 10 минут. Для первой настройки канала запусти `PUBLISH-GITHUB.bat`, введи публичный `owner/repository` и токен публикации. После этого можно изменить источник через защищённую панель разработчика. Generic HTTPS feed также поддерживается: укажи каталог с `beta.yml`, установщиком и `.blockmap` в панели. Подробная инструкция — `UPDATE-CHANNEL-RU.md`.

## Сохранность данных

Приложение сохраняет прежний Windows userData-каталог Nebula (`Nebula Launcher/NebulaLauncher`), где находятся конфигурация и игровые экземпляры. Существующие профили, моды и миры остаются на месте.

## Проверка

Перед выпуском выполни `npm.cmd install`, `npm.cmd run build` и `npm.cmd run dist:win` на Windows.
