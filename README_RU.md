# VANTA Launcher 1.4.0 — Stable Release

Десктопный лаунчер Minecraft Java на Electron + React + TypeScript.

## Что в проекте
- Профили Minecraft и загрузчики Vanilla, Fabric, Forge и NeoForge.
- Установка, запуск, диагностика и починка игровых профилей.
- Каталог Modrinth, установка модов и модпаков.
- Настройки RAM и Java Runtime.
- Друзья и обнаружение Minecraft LAN в локальной сети.
- Локальная панель разработчика с защищённой учётной записью.
- Стабильные автообновления по каналу `latest`.
- Full HD адаптивный интерфейс, рассчитанный на 1920×1080 и DPI Windows 100/125/150%.

## Требования
- Windows 10/11 x64 для сборки NSIS.
- Node.js 22 или новее и npm.

## Сборка установщика
1. Распакуй архив в папку без специальных ограничений доступа.
2. Запусти `SETUP.bat`.
3. После успешной сборки открой `release`.
4. Запусти `Vanta-Launcher-Setup-1.4.0-x64.exe`.

## Публикация стабильного автообновления
Запусти `PUBLISH-GITHUB.bat`, введи публичный `owner/repository` и GitHub token с правом Contents: Read and write. Скрипт публикует стабильный GitHub Release, `latest.yml`, установщик и `RELEASE_NOTES.md`.

Подробности: `UPDATE-CHANNEL-RU.md`.

## Данные пользователя
Приложение сохраняет существующий каталог пользовательских данных Nebula Launcher, чтобы не удалять старые игровые профили, моды и миры.
